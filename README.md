# 星火 · 1927—1937

一个能玩的**文字冒险 × 视觉小说**：从 1927 年修水的土牢，走到 1937 年过黄河。
15 章、两条线、四个结局。纯前端静态页面，双击就能玩，不需要装任何东西。

> 玩法：点击画面或按 **空格** 推进旁白；到关键节点弹出 2—4 个按钮，点按钮或按 **1 / 2 / 3 / 4** 选择。
> 右上角常驻状态栏显示 **身份 / 地点 / 时间 / 物品**，随剧情实时变化。

---

## 一、怎么玩

- **最省事**：双击 `index.html`。
- **单文件版**：双击 `星火.html`（样式和脚本已内联，方便发给别人）。
- 想自己起服务：`python3 -m http.server 8000`，然后打开 `http://localhost:8000`。

两种入口内容完全一样，`index.html` 是便于继续维护的三文件版，`星火.html` 是合并版。

## 二、怎么上线

### Netlify（推荐，两种方式都行）

1. **拖拽**：打开 <https://app.netlify.com/drop>，把整个 `星火最终版` 文件夹拖进去，几秒钟出网址。
2. **连 GitHub**：仓库建好后在 Netlify 选 *Add new site → Import an existing project*，选中该仓库，
   Build command 留空，Publish directory 填 `.`（本仓库已带 `netlify.toml`，会自动读）。

### GitHub Pages

推到 GitHub 后：*Settings → Pages → Source* 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存即可。

> 仓库根目录就是本站根目录，`index.html` 即首页，不需要构建步骤。

## 四、规模

| 项目 | 数量 |
|---|---|
| 章节 | 15 章（A—O） |
| 节点（屏） | 41 屏，每屏都有正文，不出现空屏 |
| 选择按钮 | 123 个，每一个都验过"点了必有出路" |
| 旁白/对白 | 150 句 |
| 真分叉点 | 2 个：第 5 章第三轮（2 个按钮 → F / G）、第 8 章第三轮（3 个按钮 → J / K / L） |
| 通关路线 | 4 条 |
| 结算层 | 2 个（主力线复用 IMG-14、留守线复用 IMG-15），各带时间轴与三件纪念物 |

**四条通关路线**

```
A → B → C → D → E → F → H → J → N → MAIN_END
A → B → C → D → E → F → H → K → N → MAIN_END
A → B → C → D → E → F → H → L → N → MAIN_END
A → B → C → D → E → G → I → M → O → GUERRILLA_END
```

设计上有一条铁律：**玩家的选择只改变看到的文字、物品与状态，不改变"能不能继续"**。
所以永远不会走到没有出路的地方（代码里还有一层收束兜底与占位屏兜底）。

## 五、技术说明

- **原生 JavaScript**，没有 React / Vue，没有任何第三方库，没有后端。
- 数据与引擎分离：15 章内容都在 `main.js` 顶部的 `CHAPTERS` 表里（结构为 `scene / dialogue / choices / state`），
  加章节只需要往表里加数据，引擎不用改。
- `effect` 指令解析：`trust+2`、`renown-1`（数值钳制 0—10）、`silver=taken`（枚举）、
  `items+=三块银元`（物品入栏去重）、`mementos+=铜徽章`（结算层纪念物）、`route=` / `branch=`（两处真分叉）。
- 状态分两层：状态栏只显示 **身份 / 地点 / 时间 / 物品**；`trust / renown / silver / emblem_held /
  emblem_revealed / route / branch / heard_spark` 属于内部状态，只写控制台，**永远不参与"能不能往下走"的判断**。
- 动画全部 CSS（场景淡入推近、对话框飞入飞出、选项错峰飞入、选中卡飞出、物品飞进状态栏），
  动画期间锁输入，点快了不会丢句子、不会跳过选择；支持系统级"减少动态效果"。
- 场景图槽位：`images/IMG-0X.png`（查找顺序 `.png` → `.jpg` → `.jpeg` → `.webp`）；
  **没有图也能正常玩**，画面区留白不报错。

## 六、关于图片

图片放在**站点根目录**，命名 `img01.jpg` … `img15.jpg`——现在这 15 个文件其实是**同一张风格参考图**
（革命历史油画），只为先看到画面效果，不是正式的分章图。正式图出好后**同名覆盖**即可，不用改代码。

代码里的查找顺序是 `img01.jpg` → `img01.png` → `img01.jpeg` → `img01.webp` → `images/IMG-01.jpg`，
所以换成 `.png` 也能自动认。想换目录就改 `main.js` 顶部的 `SCENE_BASE`。
控制台会打印每章实际用的是哪个文件（`[场景图] IMG-14 → img14.jpg`），找不到会列出试过的全部路径。

每章该画什么、提示词怎么写，见 **`出图提示词/README.md`**（含统一风格前缀、负面提示词、人物与道具一致性要求）。

## 七、内容与史实

剧情、按钮文案、状态字段、术语与禁用词都严格照《星火_提示词包_A+B终版》执行：

- 1927 年秋收起义军旗写 **“镰刀斧头”**，不写“镰刀锤头”；
- 1927 年江西地主武装统一写 **“靖卫团”**（不写“保安团”）；
- 1934—1937 年南方游击区武装写“红军游击队 / 独立团 / 独立营”（不写“县大队”）；
- 第 14 章为国民革命军第八路军，第 15 章为新编第四军，两章不在同一局出现。

已知取舍：提示词包建议"每段不超过 90 字"，其中两段原文（第十五段收束第 2 句 103 字、
第十一段收束第 5 句 101 字）**按原文保留**，未做删改。
